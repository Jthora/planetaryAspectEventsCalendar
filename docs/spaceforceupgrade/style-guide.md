# Space Force Interpretation Style Guide

## Audience & Persona
- **Primary**: Guardians on duty (ops floor, satellite control, ISR, cyber defense).
- **Secondary**: Command-level planners, liaison officers, and mission support staff.
- **Mindset**: Mission-first, time-constrained, balancing readiness with crew welfare.

## Voice & Tone
- Confident, precise, and respectful.
- Use mission briefing cadence: *Situation → Assessment → Recommended Action → Risk/Watch*.
- Favor verbs tied to operations ("synchronize", "harden", "vector", "stabilize").
- Keep sentences ≤ 24 words when possible.

## Structural Template
```
[Severity] Headline
Why it matters: <mission impact>
Action: <directives or coordination moves>
Watch: <intel/metrics to monitor>
Interaction Insight: <planet pair guidance>
```
- `Severity` badges align with existing enum: `Opportunity`, `Watch`, `High Risk`, `Info`.
- Headlines should mention the operating domain (orbital lanes, comms, cyber, intel, logistics) when relevant.

## Terminology Notes
| Theme | Preferred Language |
| --- | --- |
| Time windows | "next watch", "within 12 hours", "this duty cycle" |
| Collaboration | "joint cell", "cross-mission sync", "battle rhythm" |
| Risk | "threat surface", "mission drag", "readiness degradation" |
| Action | "deploy", "vector", "fortify", "stabilize", "align" |
| Monitoring | "telemetry", "sensor feeds", "intel loops" |

Avoid classified system names. Generalize: "satcom constellation", "ISR assets", "cyber shield".

## Planet & Aspect Hints
- **Sun**: Command authority, leadership beam, mission intent.
- **Moon**: Crew morale, shift readiness, emotional telemetry.
- **Mercury**: Comms bandwidth, data links, intelligence routing.
- **Venus**: Alliances, coalition support, resource diplomacy.
- **Mars**: Tactical thrust, sortie tempo, security enforcement.
- **Jupiter**: Expansion, strategic partnerships, global posture.
- **Saturn**: Discipline, compliance with doctrine, structural safeguards.
- **Uranus**: Innovation bursts, disruptive tech, autonomy pushes.
- **Neptune**: Visionary narratives, camouflaged risks, perception ops.
- **Pluto**: Deep restructures, core systems overhauls, zero-trust enforcement.

## Formatting & Glyphs
- Glyph usage matches existing modes. ASCII fallback must remain mission-friendly.
- Keep summaries ≤ ~120 characters for daily summaries.

## Review Checklist
- [ ] Severity badge matches narrative.
- [ ] Headline references a concrete mission context.
- [ ] Action line contains an imperative and a time frame.
- [ ] Watch line names a signal, sensor, or metric.
- [ ] Interaction insight bridges the two planetary themes.
